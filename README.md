# Stat

المحلل الإحصائي

موقع عربي يساعد الباحثين وطلبة الدراسات العليا على اختيار الاختبار الإحصائي المناسب، إدخال البيانات يدويًا أو عبر ملفات CSV/XLSX، عرض الجداول والرسوم، وتصدير التقرير.

## الملفات

- `index.html`: واجهة الموقع.
- `styles.css`: تنسيقات الواجهة العربية RTL.
- `app.js`: منطق التحليل الإحصائي والتصدير.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.
